# design4_fixed12_qwen36_27b

Authoritative integrated result for the 12-task, four-method, five-revision experiment.

Start with REPORT.md, then inspect trajectory_blind_gold_calibrated/tables/ for machine-readable results. Each method directory contains all r0–r5 HTML/PNG artifacts and its trace. INTEGRITY_AUDIT.json records the exhaustive generation audit.

The blind packet contains 288 main images plus 24 Gold anchors. Gold belongs only to tasks 2, 7, 10, and 12; therefore the 12-task main table has four methods, while the matched 4-task table has five methods including Gold.
